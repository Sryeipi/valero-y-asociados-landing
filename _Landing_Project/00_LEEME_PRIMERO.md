## Filosofía de este paquete

- **Minimalista pero con alma.** Nada de plantilla genérica. El bufete tiene 21 años de historia y trabaja con clientes que ya construyeron algo (familia, empresa, propiedad). La estética es "old money" + tecnología 2026.
- **Motion sutil, nunca decorativo.** Cada animación tiene un propósito: guiar la mirada, premiar el scroll, reforzar la promesa.
- **WhatsApp como spine.** La conversión vive en WhatsApp. La web entera está diseñada para que el lead caliente acabe escribiendo al número.
- **SEO local primero.** Cada bloque está pensado para posicionar las keywords del PDF estratégico ("abogado divorcios Guayaquil", etc.).
